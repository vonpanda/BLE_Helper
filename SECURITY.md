# Security Policy

## Supported Versions

Security fixes are handled on the default branch.

## Reporting a Vulnerability

Please report vulnerabilities through GitHub private vulnerability reporting if
it is available for the repository. If private reporting is unavailable, open a
minimal public issue asking for a secure contact path and avoid posting
exploit details publicly.

## Scope

BLE Helper interacts with nearby Bluetooth devices and stores local activity
logs. Reports involving unsafe BLE behavior, sensitive log exposure, malformed
firmware handling, or permission misuse are in scope.
